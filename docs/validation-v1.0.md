## 本機檢查

`npm ci`、`npm run dev`，在 Chrome 開啟 `/work.html?category=frontend`：

1. 三件前端作品可切換分類、搜尋與開啟各自內頁；返回仍保留前端分類。
2. 開啟 Network 篩選 `api.github.com`；檢查 GET 組織 repos 回應及卡片語言／日期。
3. 重新載入時看到快取來源；「更新 GitHub 資料」會重新請求。
4. 清除網站儲存並切換離線，作品仍保留，顯示重試；恢復連線後可重試成功。
5. 使用 Chrome 手機裝置預覽，確認分類按鈕、卡片與內頁沒有橫向溢出。

交付包含更新後原始碼與 dist；不包含 .git 或 node_modules，以免覆蓋本機 Git 歷史或夾帶套件。
